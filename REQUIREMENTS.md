# Requirements

## Platform

| Component | Version | Notes |
|---|---|---|
| Red Hat AAP | 2.5+ | Controller + EDA + Gateway |
| Automation Orchestrator | 2026.8+ | AO workflows, approval gates, agentic nodes |
| ServiceNow | Washington DC+ | PDI or production instance |
| Terraform | 1.5+ | For EC2 provisioning (optional) |
| AWS | Any | For demo host provisioning (optional) |

## Ansible Collections

Install via:

```bash
ansible-galaxy collection install -r ansible_deployment/cac/requirements.yml
```

| Collection | Purpose |
|---|---|
| `infra.aap_configuration` | Configuration as Code for AAP |
| `ansible.controller` | Controller API interactions |
| `servicenow.itsm` | ServiceNow incident and change request management |

## EDA Decision Environment

The EDA rulebook uses the `servicenow.itsm.records` source plugin, which requires a custom Decision Environment:

- Image: Build from `dependencies/de/decision-environment.yml` or provide your own
- Build script: `./dependencies/build-images.sh`

## Credentials Required

| Credential | Purpose | Where to Get |
|---|---|---|
| AAP OAuth Token | CaC deployment + EDA controller auth | AAP → Users → Tokens |
| ServiceNow credentials | Incident/CR management + EDA polling | ServiceNow instance admin |
| AO Webhook credentials | EDA-to-AO bridge | AO → Publish workflow → EDA trigger |
| AO Service Account | Approval bridge | AO → Settings → Service Accounts |
| AWS credentials | EC2 provisioning (optional) | AWS IAM |
| SSH key | Demo host access | Generated by Terraform |
